# Habit Tracker (iOS)

A modern habit tracking iOS application built with Swift and SwiftUI.

## Features
- Create and manage daily habits
- Track completion status and streaks
- View daily progress and statistics
- Customize habits with icons and colors
- Set daily reminder notifications

## Tech Stack
- Swift
- SwiftUI
- UserDefaults (local data persistence)
- UserNotifications

## Purpose
This project was developed to improve my iOS development skills and build real-world mobile applications with a focus on clean UI and user experience.
